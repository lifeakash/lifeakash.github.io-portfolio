# Akash — Android & Web Developer Portfolio

Personal portfolio and lead-generation site for **Akash**, an independent Android and web developer. Built as a static, single-file site for GitHub Pages — no build step, no dependencies.

**Live site:** https://lifeakash.github.io/portfolio/

## About

I design, build and publish Android apps end to end — from the first idea to a live Google Play listing — and also build fast, SEO-ready websites. This site showcases my work and lets potential clients send project details directly.

### Apps I've built
- **[GeoStamp Camera](https://play.google.com/store/apps/details?id=com.akdstudio.geostampcamera1)** — a GPS camera app that stamps photos with location, address, live map, weather, altitude and compass direction. Built for engineers, surveyors, property inspections and delivery proof.
- **[ArrowTapPuzzle Pro](https://arrowtappuzzlepro.github.io/)** — a relaxing arrow puzzle game with 100+ handcrafted levels and daily challenges.

## Features of this site

- Single self-contained `index.html`, no build tools required
- SEO: meta tags, Open Graph/Twitter cards, canonical URL, JSON-LD structured data (Person, ProfessionalService, MobileApplication, FAQPage)
- `sitemap.xml` and `robots.txt` for search engine crawling
- Lead-capture contact form (Formspree-ready, with an email fallback)
- Direct WhatsApp and email contact links
- Fully responsive, keyboard-accessible, respects reduced-motion preference

## Tech stack

Plain HTML, CSS and vanilla JavaScript. No frameworks, no build pipeline — deploys as-is to GitHub Pages.
